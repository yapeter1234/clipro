# Browser source capture quick guide

This guide covers what to do before a source file enters Clipro. Choose the source platform and whether the moment is happening live or in a past broadcast.

## Twitch — live or past broadcast

1. Sign in to Twitch.
2. Open the channel's live stream or past broadcast.
3. Select the Clip icon to open Clip Creator.
4. Trim the moment (5–60 seconds), including enough setup and payoff.
5. Create the native Twitch clip.
6. Open your Clips Manager and download the clip you created (landscape or portrait).
7. In Clipro, choose Twitch, Live stream or Past broadcast, paste the channel/clip reference, and upload the MP4.

Viewer-created clips can be made only when the channel's settings allow clipping and your viewer account is not restricted. A viewer can download clips they created. Clipro does not use the editor-only clip-download API in viewer mode.

Official help: https://help.twitch.tv/s/article/how-to-use-clips

## Kick — live or VOD

1. Sign in to Kick.
2. Open the creator's live stream or VOD.
3. Click the Clip icon or press C.
4. Choose a 10–180-second moment and create the clip.
5. Open the clip and select Download.
6. In Clipro, choose Kick, Live stream or Past broadcast, paste the clip/channel URL, and upload the MP4.

Kick does not let viewers download another creator's full VOD. Use a native viewer-created clip or obtain an authorized file from the creator/campaign.

Official help: https://help.kick.com/en/articles/7120566-how-to-create-clips-on-kick

## YouTube — live or archived video

YouTube's Clip feature creates a public 5–60-second reference/loop that plays from the original video. It is not a general MP4 download. Live clipping requires DVR and other eligibility conditions; clips may not become playable until the live stream has ended and its archive is available.

For Clipro editing, request an authorized source file/excerpt from the creator/campaign, then upload the file. A YouTube Clip URL can be attached as a reference, but it is not treated as video media.

Official help: https://support.google.com/youtube/answer/10332730

## Upload checklist

Before clicking Analyze:
- Select the correct platform and source type.
- Add the original channel/video/clip URL as provenance.
- Confirm that you are authorized by the campaign/creator to edit and publish the material.
- Upload the actual video file (a public URL alone is not sufficient).
- Do not submit screen recordings.
- Confirm the file contains the intended creator/game/moment.
- Select the correct campaign profile, if applicable.

Clipro then analyzes and edits the uploaded file. It does not publish anything; you download the finished render and post it yourself.
